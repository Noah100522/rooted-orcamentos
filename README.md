# Rooted Orçamentos IA

Aplicação web para criação, revisão e geração de orçamentos da Rooted Informática.

## Stack inicial

- Next.js + TypeScript
- Tailwind CSS
- Estrutura preparada para Gemini, Supabase e sobreposição de PDF

## Desenvolvimento

```bash
npm install
npm run dev
```

> O modelo oficial de PDF deverá ser configurado em uma etapa posterior, usando o arquivo original como base imutável para sobreposição.
